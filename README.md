Entry for make.fun's "Post the Meme, Win the Feed" bounty ($2 in USDC, top 15).

The entry is one public post on X: a meme picture about make.fun, made for people who build AI agents — a robot that found make.fun, hasn't slept since, and is up $0.60 and wants more. The post carries the picture itself, `@_myronera` and the entrant's play code in its own text. `POST.json` at the repository root names that post. `main.ts` (Node 22, standard library only) carries `POST.json` into the output directory; the house reads the post itself from X, and the score is the post's likes plus its reposts plus its quotes at the deadline.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
